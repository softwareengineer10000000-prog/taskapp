# 📝 TaskApp - PWA Task Manager

A full-stack Progressive Web Application (PWA) designed to manage daily tasks efficiently. Built using vanilla JavaScript on the frontend and PHP on the backend.

![TaskApp Banner](https://via.placeholder.com/800x400?text=TaskApp+Screenshot)

---

## 🚀 Key Features

- **Offline Capability:** Native PWA support allows off-line task access via Service Workers.
- **Task Management:** Create, read, update, and delete daily tasks in real time.
- **RESTful PHP API:** Clean backend endpoints handling data operations.
- **Responsive UI:** Clean CSS design optimized for desktop and mobile screens.

## ⚙️ Local Setup & Installation

### Prerequisites
- PHP 8.x installed locally or via local server (XAMPP/WAMP/MAMP)
- A modern web browser

### Steps
1. **Clone the repository:**
    bash
      git clone https://github.com/softwareengineer10000000-prog/taskapp.git
      cd taskapp

2. **Start local PHP server:**
   bash
      php -S localhost:8000

3. **Open in browser:**
    Navigate to `http://localhost:8000` in your browser.
